# Бюджет 2026

Месячный планировщик личного бюджета по вкладке **Бюджет_2026** из Numbers:
рабочие дни, доходы (ЗП / аванс / КВ / брокер), категории расходов (план и факт), остаток.

## Открыть

**https://rus89nur.github.io/personal-budget/**

Локально:

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8080`.

## Модель

Как на листе Бюджет_2026:

- выбор месяца 2026;
- **рабочие дни** — всего / работаю / отпуск;
- **доходы** — ЗП предыдущего месяца, аванс, КВ (пассив квартир), брокер/вклад и разовые;
- **расходы** — категории с **планом** (из таблицы) и **фактом**;
- **остаток** = доходы − расходы (план).

Стартовые цифры загружаются из `seed-data.json` (разбор таблицы).
Всё правится в интерфейсе и пишется в `localStorage` (`personal-budget-v2`).
Есть **экспорт / импорт JSON** и кнопка **Из таблицы** для сброса к сиду.

## Деплой
