# Личный бюджет

Простой публичный веб-учёт доходов и расходов для Rus89nur.
Сделан по модели таблицы Numbers: те же категории (ЗП, Жили были, Ипотека, Комуналка, Отложить и др.), учёт по месяцам и понятный баланс.

## Открыть сайт

После публикации на GitHub Pages:

**https://rus89nur.github.io/personal-budget/**

Локально:

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8080`.

## Что умеет

- добавить / изменить / удалить операцию;
- доход или расход;
- категории из вашей таблицы;
- дата и сумма;
- фильтр по месяцу, типу и категории;
- баланс периода и накопительный остаток;
- импорт и экспорт JSON.

## Где хранятся данные

Все операции сохраняются **только в браузере** (`localStorage` ключ `personal-budget-v1`).
Сервера и облачной синхронизации нет: на другом устройстве или после очистки данных сайта список будет пустым.
Для переноса используйте кнопки **Экспорт** и **Импорт**.

## Деплой

Репозиторий публичный. GitHub Actions (`.github/workflows/deploy-pages.yml`) публикует содержимое `main` на GitHub Pages.
